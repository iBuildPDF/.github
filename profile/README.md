# iBuildPDF

Free, practical PDF tools designed around privacy, simplicity and useful workflows.

🌐 **Website:** https://ibuildpdf.com

## What is iBuildPDF?

iBuildPDF provides online tools for everyday PDF tasks, including:

- Merge PDF files
- Split and extract PDF pages
- Compress PDF files
- Convert PDFs and images
- Edit and sign PDFs
- Organize, rotate and resize pages
- Remove metadata and redact sensitive information
- Inspect and compare PDF documents

## Privacy-first processing

Most iBuildPDF tools process documents directly in the browser, so files do not need to leave the user's device.

Some advanced conversions and OCR operations require secure server-side processing and are clearly identified when used.

## Smart Search

Instead of searching through long tool menus, users can describe what they want to do, such as:

- “make my PDF smaller”
- “combine these PDFs”
- “remove some pages”
- “turn my photos into a PDF”

iBuildPDF then helps find the appropriate tool.
